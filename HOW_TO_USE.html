01

Install

Qalam has no required dependencies. The core pipeline runs on pure Python 3.10+.

terminal 
# minimal install
pip install qalam

# with HuggingFace Hub push support
pip install qalam[hub]

# everything
pip install qalam[all]
tip No model downloads required. Dialect detection and quality scoring are lexicon-based and run instantly — even on a laptop.

Modules available after install:

normalize
Unicode, alef/hamza, Persian chars, diacritics, tatweel, bidi, numerals
dialect
Detect & route 8 varieties — optional MADAR profile (78.6% acc, no GPU)
quality
Score and filter by Arabic ratio, noise, repetition, boilerplate, toxicity
dedup
Exact + MinHash LSH near-dedup, cross-dataset contamination
formats
SFT, DPO, pretraining — 12 chat templates for every major Arabic LLM
report
HTML report card with interactive dialect map
02

Full pipeline

The easiest way to use Qalam is the Pipeline orchestrator — it chains all modules in the right order.

normalize → dialect filter → quality filter → dedup → format → report
python — one liner 
from qalam import Pipeline

result = Pipeline().run(my_texts)
print(f"Kept {len(result.texts)} / {len(my_texts)} examples")
python — full config 
from qalam import Pipeline
from qalam.pipeline import PipelineConfig
from qalam.normalize import NormalizerConfig
from qalam.quality   import QualityConfig

pipeline = Pipeline(PipelineConfig(
    normalizer     = NormalizerConfig(diacritics="strip"),
    quality        = QualityConfig(min_quality_score=0.6),
    dialect_filter = ["MSA", "EGY"],  # keep only MSA + Egyptian
    run_dedup      = True,
    generate_report= True,
    report_path    = "report.html",
))

result = pipeline.run(texts)
print(result.stats)
python — load from file 
# reads .jsonl ({"text": "..."} per line) or plain .txt
result = pipeline.run_from_file("data.jsonl", column="text")
config presets Three ready-made YAML presets live in configs/: pretraining.yaml, sft.yaml, and classical.yaml (keeps diacritics for Quranic / classical text).
03

Normalize

Handles the script-level noise that breaks tokenizers: multiple alef forms, tatweel elongation, diacritics, Eastern numerals, HTML, and Unicode presentation forms.

python 
from qalam import QalamNormalizer
from qalam.normalize import NormalizerConfig

# default: strip diacritics, unify alef, remove tatweel
n = QalamNormalizer()
n.normalize("مَرْحَبًا بِكُم")
# → "مرحبا بكم"

# keep diacritics (classical / Quranic data)
n = QalamNormalizer(NormalizerConfig(diacritics="keep"))

# see exactly what changed
diff = n.diff(original, n.normalize(original))
# {"changed": True, "changes": ["diacritics stripped", "2 alef variant(s) unified"]}

# batch
clean_texts = n.normalize_batch(texts)

Dialect detection

Identifies which variety of Arabic a text is written in — and lets you keep, exclude, tag, or separate by dialect. This is the most uniquely Arabic problem Qalam solves.

MADAR-6 benchmark DialectDetector(profile="madar") scores 78.6% accuracy on the standard 6,000-sample MADAR-6 benchmark — within 1.4 points of MARBERT (500 MB PyTorch model) at 1/1250th the install size. The default mode hits 91% precision when it commits to a label (abstains on uncertain texts).
python 
from qalam import DialectDetector

# default: fast IDF-weighted lexicon — no model, instant
d = DialectDetector()

# high-accuracy mode: MADAR profile (78.6% on MADAR-6, 400 KB, no GPU)
d = DialectDetector(profile="madar")

# detect a single text
result = d.detect("عايز أروح السينما النهارده")
result.dialect       # "EGY"
result.confidence    # 0.85
result.country_hints # ["EGY"]

# filter a corpus — keep only MSA
msa = d.route(texts, keep=["MSA"])

# exclude Maghrebi
filtered = d.route(texts, exclude=["MAG"])

# tag every example with metadata
tagged = d.tag_batch(texts)
# [{"text": "...", "dialect": "LEV", "confidence": 0.79}, ...]

# corpus distribution (used by the map visualizer)
dist = d.distribution(texts)
# {"total": 1000, "dialects": {"EGY": {"count": 350, "percentage": 35.0}}}

Quality scoring

Scores each text on five dimensions and returns a composite 0–1 score. Texts below the threshold are flagged with the reason.

python 
from qalam import QualityScorer
from qalam.quality import QualityConfig

scorer = QualityScorer(QualityConfig(
    min_arabic_ratio   = 0.5,
    min_length         = 50,
    min_quality_score  = 0.55,
    check_toxicity     = True,
    check_boilerplate  = True,
))

# score one text
r = scorer.score(text)
r.score          # 0.82
r.passed         # True
r.flags          # [] or ["too_short", "high_noise", ...]
r.arabic_ratio   # 0.89

# filter a list
clean = scorer.filter_batch(texts)

# corpus summary
summary = scorer.summary(texts)
# {"total": 1000, "passed": 847, "pass_rate": 84.7, "flag_breakdown": {...}}

Deduplication

Two-phase dedup: exact fingerprinting catches perfect copies; MinHash LSH catches near-duplicates that are paraphrases or slightly edited versions. Cross-dataset contamination detection is also built in.

python 
from qalam import Deduplicator
from qalam.dedup import DedupConfig

deduper = Deduplicator(DedupConfig(
    near_dedup_threshold = 0.8,  # Jaccard similarity cutoff
    num_perm             = 128,  # MinHash permutations
))

result = deduper.dedup(texts)
result.removed_count   # total removed
result.exact_removed   # exact duplicates
result.near_removed    # near-duplicates
result.duplicate_rate  # e.g. 12.4 (percent)
result.unique_texts    # clean list

# cross-dataset: remove train examples that appear in test set
clean_train = deduper.dedup_against(train_texts, test_texts)

# contamination report
report = deduper.contamination_report(train_texts, test_texts)
# {"contamination_rate": 2.3, "contaminated_train_examples": 230}
threshold guide 0.9+ — very strict, only catches near-identical texts (good for fine-tuning). 0.8 — catches paraphrases (good for pretraining). 0.7 — aggressive, may remove legitimate variations.

Format conversion

Convert cleaned data into whatever format your training framework expects — with the right chat template applied.

python — SFT + chat templates 
from qalam import FormatConverter
from qalam.formats import SFTExample, DPOExample

conv = FormatConverter(default_template="chatml")

# create an SFT example
ex = SFTExample(
    instruction = "ما هي عاصمة مصر؟",
    input       = "",
    output      = "عاصمة مصر هي القاهرة.",
)

# pick any of the 12 supported templates
conv.sft_to_formatted(ex, template="llama3")    # Llama 3 / 3.1 / 3.2
conv.sft_to_formatted(ex, template="llama2")    # Llama 2 Chat
conv.sft_to_formatted(ex, template="mistral")   # Mistral / Mixtral / ALLaM
conv.sft_to_formatted(ex, template="chatml")    # Qwen, Yi, AceGPT, Jais-v2
conv.sft_to_formatted(ex, template="jais")      # Jais (Arabic-first)
conv.sft_to_formatted(ex, template="gemma4")    # Gemma 4
conv.sft_to_formatted(ex, template="gemma2")    # Gemma 2 / 3
conv.sft_to_formatted(ex, template="command-r") # Command-R / Aya / Aya-Expanse
conv.sft_to_formatted(ex, template="phi3")      # Phi-3 / Phi-3.5
conv.sft_to_formatted(ex, template="deepseek")  # DeepSeek V2 / V3 / R1
conv.sft_to_formatted(ex, template="alpaca")    # Stanford Alpaca / academic
conv.sft_to_formatted(ex, template="vicuna")    # Vicuna 1.1 / FastChat

# Gemma 4 with chain-of-thought thinking mode
from qalam.formats import CHAT_TEMPLATES
CHAT_TEMPLATES["gemma4"]["enable_thinking"] = True
conv.sft_to_formatted(ex, template="gemma4")

# generate inference prompt (no assistant response appended)
conv.apply_chat_template(messages, template="llama3", add_generation_prompt=True)

# save as JSONL
conv.save_jsonl(examples, "train.jsonl")

# DPO format
dpo = DPOExample(
    prompt   = "كيف أتعلم البرمجة؟",
    chosen   = "ابدأ بتعلم Python عبر مشاريع عملية...",
    rejected = "اقرأ كتب.",
)
conv.dpo_to_dict(dpo)  # ready for TRL DPOTrainer

# pretraining: concatenate with EOS tokens
conv.to_pretraining(texts, eos_token="</s>")

# push to HuggingFace Hub
conv.push_to_hub(examples, "your-org/arabic-sft")

Report card

Generates a full dataset report — token counts, quality distribution, dialect breakdown, duplicate rates — exportable as HTML (with the interactive dialect map), JSON, or Markdown for dataset cards.

python 
from qalam.report import ReportGenerator

gen = ReportGenerator()
report = gen.generate(texts)

# print summary to terminal
gen.print_summary(report)

# save interactive HTML report (includes dialect map)
gen.save_html(report, "report.html", dataset_name="My Dataset")

# machine-readable JSON
gen.save_json(report, "report.json")

# HuggingFace dataset card section (Markdown)
print(gen.to_markdown(report))
dialect map visualizer Open scripts/dialect_map_visualizer.html in any browser. Drag and drop your JSONL file — no server needed. The Arab world lights up showing exactly where your data comes from. A bias alert fires if one dialect exceeds 65%.
09

CLI reference

Every feature is available from the command line. The qalam command is installed automatically with the package.

terminal — clean 
# basic clean
qalam clean data.jsonl --output clean.jsonl

# keep MSA only, generate HTML report
qalam clean data.jsonl \
  --dialect msa \
  --output msa.jsonl \
  --report-html report.html

# SFT format with Llama-3 template, strict quality
qalam clean data.jsonl \
  --format sft \
  --template llama3 \
  --quality-threshold 0.65 \
  --output train.jsonl

# keep diacritics (classical text)
qalam clean quran.jsonl --diacritics keep --output quran_clean.jsonl
terminal — report & dedup 
# generate report card
qalam report data.jsonl --out report.html --json report.json

# print markdown (for HuggingFace dataset cards)
qalam report data.jsonl --markdown

# dedup only
qalam dedup data.jsonl --threshold 0.8 --output deduped.jsonl

# exact dedup only (faster, no MinHash)
qalam dedup data.jsonl --exact-only --output deduped.jsonl

# show all options and dialect codes
qalam info
